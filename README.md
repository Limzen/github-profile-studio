## 🏅 Panduan Lengkap Lencana GitHub

Ingin mengoleksi badge di profil GitHub seperti **Starstruck**, **Pull Shark**, dan **Quickdraw**?

Kami telah menyusun panduan trik cepatnya di dokumen khusus:
👉 **[Buka Panduan Lengkap Lencana GitHub (docs/GITHUB_BADGES_GUIDE.md)](./docs/GITHUB_BADGES_GUIDE.md)**

### Ringkasan Cepat Badge:
- ⭐ **Starstruck**: Dapatkan bintang pada repo publik Anda (16, 128, 512, 4.096 stars).
- 🦈 **Pull Shark**: Merge Pull Request (2, 16, 128, 1024 PRs).
- ⚡ **Quickdraw**: Buka lalu langsung tutup Issue/PR dalam 5 menit.
- 🤠 **YOLO**: Merge Pull Request tanpa review.
- 👥 **Pair Extraordinaire**: Tambahkan `Co-authored-by` pada pesan commit.

## 📖 Cara Pasang di Profil GitHub Anda

1. Di GitHub, buat repositori baru dengan nama yang **sama persis dengan username Anda** (Contoh: jika username Anda `budi123`, buat repo bernama `budi123`).
2. Pastikan opsi **Public** dicentang.
3. Centang opsi **Add a README file**.
4. Buka file `README.md` yang baru dibuat di repo tersebut, lalu salin dan tempel salah satu template pilihan Anda dari repo ini.
5. Ganti teks `<YOUR_GITHUB_USERNAME>` dengan username GitHub Anda yang sebenarnya.
6. Klik **Commit changes** — halaman profil GitHub Anda sekarang tampil memukau!
