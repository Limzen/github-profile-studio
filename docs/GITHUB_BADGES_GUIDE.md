# 🏅 Panduan Lengkap Membuka Semua Badge & Achievement GitHub

Panduan ini berisi cara paling praktis, cepat, dan legal untuk membuka seluruh lencana (achievements) di profil GitHub Anda.

---

## 🏆 Daftar Badge & Cara Membukanya

### 1. ⭐ Starstruck
- **Misi**: Memiliki repositori publik yang disukai dan diberi bintang (*Star*) oleh pengguna lain.
- **Tingkatan (Tiers)**:
  - 🥉 **Base**: 16 Stars
  - 🥈 **Bronze**: 128 Stars
  - 🥇 **Silver**: 512 Stars
  - 💎 **Gold**: 4,096 Stars
- **Trik Tercepat Mendapatkannya**:
  1. Buat repositori seperti template profil ini atau *curated awesome list*.
  2. Bagikan ke komunitas (Discord programmer, grup Telegram, thread X/Twitter, LinkedIn).
  3. Minta teman satu kampus/kantor untuk memberikan 16 bintang pertama.

---

### 2. 🦈 Pull Shark
- **Misi**: Memiliki *Pull Request* (PR) yang berhasil di-*merge* ke dalam repositori.
- **Tingkatan (Tiers)**:
  - 🥉 **Base**: 2 PRs merged
  - 🥈 **Bronze**: 16 PRs merged
  - 🥇 **Silver**: 128 PRs merged
  - 💎 **Gold**: 1,024 PRs merged
- **Trik Cepat**:
  - Anda bisa membuat repositori sendiri, membuat branch baru (`git checkout -b feature`), lalu membuat Pull Request ke `main` dan me-*merge*-nya sendiri! GitHub menghitung PR di repo Anda sendiri!

---

### 3. ⚡ Quickdraw
- **Misi**: Menutup (*close*) sebuah issue atau Pull Request dalam waktu kurang dari 5 menit setelah dibuat.
- **Tingkatan**: 1 Tier (Langsung dapat).
- **Cara Mendapatkannya (Dalam 1 Menit)**:
  1. Buka salah satu repositori milik Anda sendiri.
  2. Buat Issue baru dengan judul sembarang, misal `Testing issue`.
  3. Klik **Submit new issue**.
  4. Langsung klik tombol **Close issue** sebelum 5 menit (dalam hitungan detik).
  5. Refresh profil GitHub Anda, badge **Quickdraw** langsung aktif!

---

### 4. 🤠 YOLO
- **Misi**: Melakukan merge sebuah Pull Request tanpa *code review*.
- **Tingkatan**: 1 Tier.
- **Cara Mendapatkannya**:
  1. Di repo Anda sendiri, buat branch baru dan buka Pull Request.
  2. Langsung klik tombol **Merge pull request** dan **Confirm merge** tanpa meminta review dari siapa pun.
  3. Badge **YOLO** akan otomatis terbuka!

---

### 5. 👥 Pair Extraordinaire
- **Misi**: Menjadi *co-author* dalam sebuah commit yang berhasil di-merge.
- **Tingkatan (Tiers)**:
  - 🥉 **Base**: 1 commit
  - 🥈 **Bronze**: 10 commits
  - 🥇 **Silver**: 24 commits
  - 💎 **Gold**: 48 commits
- **Cara Mendapatkannya**:
  Saat melakukan commit git, tambahkan baris `Co-authored-by` di bagian akhir pesan commit:
  ```bash
  git commit -m "Add new feature

  Co-authored-by: NamaTeman <email-teman@example.com>"
  ```
  Push ke GitHub, dan badge ini akan langsung terbuka bagi Anda dan rekan yang Anda sebutkan!

---

### 6. 🧠 Galaxy Brain
- **Misi**: Memiliki jawaban yang diterima (*accepted answer*) pada fitur GitHub Discussions.
- **Tingkatan (Tiers)**:
  - 🥉 **Base**: 2 accepted answers
  - 🥈 **Bronze**: 8 accepted answers
  - 🥇 **Silver**: 16 accepted answers
  - 💎 **Gold**: 32 accepted answers
- **Cara Mendapatkannya**:
  1. Aktifkan tab **Discussions** di repo Anda sendiri (Settings -> Features -> Centang Discussions).
  2. Ajukan pertanyaan di kategori Q&A.
  3. Gunakan akun kedua atau ajak teman untuk menjawab, lalu tandai jawabannya sebagai "Mark as answer". Atau jawab pertanyaan orang lain di repositori open source besar seperti Next.js, Vercel, Supabase.

---

### 7. 💖 Public Sponsor
- **Misi**: Menjadi sponsor bagi developer atau proyek open-source lain melalui GitHub Sponsors.
- **Tingkatan**: 1 Tier.
- **Cara Mendapatkannya**:
  - Sponsori developer open source favorit Anda mulai dari $1/bulan via GitHub Sponsors (bisa dibatalkan setelahnya jika diinginkan).

---

## 📌 Cara Menampilkan Badge di Profil GitHub Anda

1. Buka profil GitHub Anda (`https://github.com/<username>`).
2. Di sidebar kiri bawah bagian **Achievements**, klik icon gear (⚙️) atau tombol **Edit Highlights**.
3. Pilih hingga 4 badge favorit Anda untuk dipajang sebagai sorotan utama (*Showcased Achievements*).
