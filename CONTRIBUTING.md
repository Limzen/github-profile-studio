# Panduan Kontribusi 🤝

Terima kasih atas minat Anda untuk berkontribusi pada repositori ini! Komunitas open source tumbuh karena kontribusi dari pengembang seperti Anda.

## Cara Berkontribusi

1. **Laporkan Bug atau Beri Masukan**: Jika menemukan broken link, widget yang tidak tampil, atau punya ide template baru, silakan buka **Issue**.
2. **Kirim Template Baru**:
   - Buat file baru di dalam folder `templates/` (misalnya `09-nama-template.md`).
   - Pastikan format Markdown rapi dan menggunakan placeholder seperti `<YOUR_GITHUB_USERNAME>`.
   - Update daftar di `README.md`.
3. **Alur Pull Request**:
   - Fork repositori ini.
   - Buat branch: `git checkout -b feature/nama-fitur`.
   - Lakukan commit: `git commit -m "feat: add template XYZ"`.
   - Push ke fork: `git push origin feature/nama-fitur`.
   - Buka Pull Request (PR) ke branch `main`.

Setiap kontribusi yang masuk akan kami review dengan senang hati!
