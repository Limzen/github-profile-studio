GitHub Achievements Manual

Unlock Verified Developer Badges

Actionable pathways to obtain all official GitHub community achievements.

Starstruck

Stars received on personal public repository
Base: 16 ⭐ Bronze: 128 ⭐ Silver: 512 ⭐

Direct Pathway: Publish this profile studio repository, share the interactive demo with fellow developers to gather 16 initial stars.

Pull Shark

Pull requests opened and merged into main
Base: 2 PRs Bronze: 16 PRs Silver: 128 PRs

Direct Pathway: Open a feature branch on your own repository, create a PR to main, and merge it. GitHub counts self-merged PRs.

Quickdraw

Closed an issue or pull request within 5 minutes
Single Tier Unlock

Direct Pathway: Create a dummy issue in any repository you own, then click "Close Issue" within 60 seconds.

YOLO

Merged a pull request without code review
Single Tier Unlock

Direct Pathway: Merge any pull request directly on your repository without adding or requesting reviewers.

Pair Extraordinaire

Co-authored a commit in a merged PR
Base: 1 Commit Bronze: 10 Commits

Direct Pathway: Append Co-authored-by: Name <email> to your git commit message.

Galaxy Brain

Accepted answers in GitHub Discussions
Base: 2 Answers Bronze: 8 Answers

Direct Pathway: Enable Discussions tab in repository settings, post a Q&A thread, and mark the response as the accepted answer.
