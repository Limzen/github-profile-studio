Unlock Every GitHub Badge

Quick tips to earn community badges on your GitHub profile.

⭐

Starstruck

Created a repository that received stars from others.

Base: 16 ⭐ Bronze: 128 ⭐ Silver: 512 ⭐
💡 Fast track: Publish this profile template repo on GitHub, share it to your friends & Discord communities!
🦈

Pull Shark

Opened pull requests that have been merged.

Base: 2 PRs Bronze: 16 PRs Silver: 128 PRs
💡 Fast track: Create a branch on your own repo, open a PR to main, and merge it!
⚡

Quickdraw

Closed an issue or pull request within 5 minutes of opening.

1-Tier Instant
💡 Fast track: Open a dummy issue in your repo, then click "Close Issue" immediately.
🤠

YOLO

Merged a pull request without code review.

1-Tier Instant
💡 Fast track: Merge your own PR directly without assigning any reviewers.
👥

Pair Extraordinaire

Co-authored a commit in a merged pull request.

Base: 1 Commit Bronze: 10 Commits
💡 Fast track: Add Co-authored-by: Name <email> at the end of git commit message!
🧠

Galaxy Brain

Had your answer accepted in GitHub Discussions.

Base: 2 Answers Bronze: 8 Answers
💡 Fast track: Enable Discussions tab in your repo, ask a question and mark the reply as answer.
